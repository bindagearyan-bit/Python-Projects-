DESIGN CONCEPT
"Match Ticket" brings the classic Rock Paper Scissors game into a sleek, warm parchment ticket-stub UI. Inspired by vintage admission tickets, it pairs bold Bebas Neue headlines with retro Space Mono scoring data and deep crimson red (#C1272D) accents.
TECH STACK
Built with Python Flask, dynamic Jinja2 templates, lightweight in-memory session management, and HTML5 Canvas confetti celebrations.
FLASK 3.x JINJA2 BEBAS NEUE SPACE MONO NO-SFX

Hard difficulty mode incorporates pattern tracking that records your historical choices and calculates optimal counter-moves to challenge seasoned players.
